= Audiovisual Live Coding System
:toc:
:toclevels: 3
:sectnums:

== 1. Concept

음악과 비주얼을 별개의 reactive system으로 만들지 않고, 하나의 시간축과 하나의 퍼포먼스 언어로 묶는다.

핵심 아이디어는 다음과 같다.

* *Ableton*은 실제 음색과 연주 파라미터를 담당한다.
* *Strudel*은 음악 패턴과 비주얼 파라미터를 동시에 작곡하는 상위 제어 레이어다.
* *TouchDesigner*는 고정된 3D 씬, 움직임, 파티클, 피드백, 합성을 실시간으로 담당한다.
* *AI*는 3D geometry를 생성하는 것이 아니라 texture / material / style / appearance를 공급한다.
* AI 결과는 매 프레임 생성하지 않고, 패턴이나 씬이 바뀔 때 갱신되는 texture source로 사용한다.

따라서 최종 시스템은 <<audiovisual-instrument>>에 가깝다.

== 2. System Architecture

[source,text]
----
                ABLETON
       audio / synth / macro controls
                    |
                    | MIDI / OSC
                    v
                 STRUDEL
     music + motion + scene + material score
                    |
                    | OSC
                    v
             TOUCHDESIGNER
   +---------------------------------------+
   | fixed 3D scene                       |
   | camera / geometry / particles        |
   | audio-reactive movement              |
   | alpha / feedback / compositing       |
   +------------------+--------------------+
                      |
                      | image / Spout
                      v
                AI IMAGE EDIT
          StreamDiffusion / SDXL / etc.
                      |
                texture result
                      v
             TOUCHDESIGNER FEEDBACK
                      |
                      v
                   OUTPUT
----

== 3. Role Separation

=== 3.1 Ableton Live

실제 사운드 엔진과 연주자의 물리적 조작을 담당한다.

권장 방식은 개별 플러그인의 수많은 파라미터를 직접 비주얼에 연결하는 것이 아니라, 의미 있는 Macro를 만든 뒤 오디오와 비주얼에 동시에 매핑하는 것이다.

예:

[cols="1,2,2"]
|===
|Macro | Audio | Visual

|Pad / Air
|reverb, filter brightness, chorus
|membrane alpha, particle spread, texture brightness

|Pad / Tension
|resonance, distortion
|cloth deformation, feedback amount

|Bass / Weight
|sub level, saturation
|sphere scale, deformation, visual density

|Kick / Impact
|transient/body
|sphere pulse, displacement burst, flash
|===

즉 하나의 Macro가 소리와 물질을 동시에 연주한다.

== 4. Strudel as Audiovisual Score

Strudel의 parameter는 독립적인 Pattern으로 제어할 수 있으며 custom parameter도 만들 수 있다. MIDI/OSC 출력도 지원하므로 음악 패턴과 비주얼 상태를 같은 시간축에서 운용하는 기반으로 적합하다.

Reference: https://strudel.cc/technical-manual/repl/

=== 4.1 Parameter Domains

[cols="1,2,2"]
|===
|Domain | Examples | Destination

|Music
|note, velocity, cutoff, gain
|Ableton / MIDI

|Motion
|motion, deform, rotation, scale
|TouchDesigner CHOP / parameter

|Dynamics
|amp, intensity, energy
|TD amplitude / FX / alpha

|Scene
|scene, layer, camera
|TD scene selection

|Material
|material, texture, style
|AI prompt / texture bank

|Appearance
|detail, lighting, palette
|AI prompt composer / TD material

|Feedback
|feedback, decay, displacement
|TD feedback network
|===

=== 4.2 Example: Pad Layer

[source,javascript]
----
// 개념 예시
$: note("<c3 eb3 g3>")
  .layer("pad")
  .amp("<0.3 0.6 0.9 0.5>")
  .alpha("<0.1 0.4 0.7 0.5>")
  .deform("<0.1 0.3 0.8 0.4>")
  .material("translucent-fabric")
  .style("soft-organic")
----

여기서 `alpha`, `deform`, `material`, `style` 등은 시스템에서 정의한 custom parameter로 구현한다. Strudel custom parameter는 custom output에 의미를 부여해야 실제 외부 시스템을 제어한다.

== 6. 3D Scene Strategy

3D geometry와 camera는 TouchDesigner에서 고정된 구조를 가진다.

AI에게 3D scene을 새로 생성시키는 것이 아니라 다음과 같이 역할을 분리한다.

[source,text]
----
TouchDesigner
    3D geometry
    camera
    spatial movement
    particles
    lighting structure
         |
         v
      render
         |
         v
      AI i2i
         |
         v
 texture / material / style
         |
         v
      TD composite
----

이렇게 하면 geometry drift와 camera drift를 줄이고, AI를 appearance generator로 제한할 수 있다.

== 7. AI Texture Pipeline

AI는 지속적으로 프레임을 생성하지 않는다.

=== 7.1 Pattern-triggered generation

패턴이나 씬이 바뀔 때 새로운 이미지를 생성한다.

[source,text]
----
Pad pattern starts
        |
        v
request material image
        |
        v
AI i2i / image edit
        |
        v
texture bank
        |
        v
TouchDesigner
----

=== 7.2 Texture Bank

생성된 이미지는 즉시 버리는 프레임이 아니라 texture library로 유지한다.

예:

[source,text]
----
PAD
  membrane_01
  membrane_02
  membrane_03

BASS
  organic_01
  chrome_01
  liquid_01

KICK
  ceramic_01
  stone_01
  metal_01
----

공연 중에는 Strudel의 material/scene 패턴에 따라 texture를 교체하고, AI는 백그라운드에서 다음 variation을 준비한다.

== 8. TouchDesigner Feedback

AI가 만든 한 장의 이미지를 실제 영상으로 확장하는 핵심은 TD의 feedback network다.

[source,text]
----
AI texture
    |
    v
Transform
    |
    v
Displace
    |
    v
Level / Alpha
    |
    v
Feedback
    |
    +----> Blur / Color / Warp
    |
    +----> Composite
             |
             +----> output
----

AI 결과 한 장이 수백 개의 프레임으로 계속 변형되므로 AI latency와 최종 영상 framerate를 분리할 수 있다.

권장 초기 목표:

* TouchDesigner: 60 fps
* AI texture refresh: 약 1-5 fps 또는 패턴 변화 시에만
* 출력: 24/30/60 fps

== 9. Similarity-aware AI Refresh

StreamDiffusion 계열에서는 이전 프레임과 현재 프레임의 유사도가 높으면 inference를 건너뛰는 Stochastic Similarity Filter를 사용할 수 있다.

이 아이디어를 본 시스템에도 적용한다.

[source,text]
----
TD 60 fps
   |
   v
similarity check
   |
   +-- 변화 작음 --> 기존 AI texture 유지
   |
   +-- 변화 큼 ----> AI inference
                         |
                         v
                    새 texture
----

즉 AI의 계산량을 음악적/시각적 변화량에 맞춘다.

== 10. Scene Composition Example

=== 10.1 Minimal Scene

중앙에 고정된 sphere 하나를 둔다.

[source,text]
----
                 [ PAD MEMBRANE ]
               ~~~~~~~~~~~~~~~~~~~
             ~~                   ~~
           ~~        SPHERE         ~~
             ~~                   ~~
               ~~~~~~~~~~~~~~~~~~~

                   particles
----

=== 10.2 Music Mapping

* Kick: sphere가 순간적으로 팽창한다.
* Bass: sphere의 전체적인 deformation과 mass가 변한다.
* Pad: sphere를 둘러싼 얇은 membrane이 나타나고 사라진다.
* Snare: membrane 또는 sphere에 짧은 fracture/displacement가 발생한다.
* Hi-hat: 미세 particle과 표면 jitter가 발생한다.

=== 10.3 Pad Example

Pad가 들어오면 다음 상태가 동시에 변화한다.

[source,text]
----
Pad Air ↑
  -> Reverb ↑
  -> membrane alpha ↑
  -> membrane spread ↑
  -> texture brightness ↑
  -> fine fiber detail ↑
----

소리와 시각이 같은 control source에서 움직인다.

== 11. Ableton <-> Strudel <-> TD

전체 시스템에서 Strudel은 반드시 오디오 엔진을 대체할 필요가 없다.

[source,text]
----
                 Strudel
               /          \
              /            \
           MIDI              OSC
            |                  |
            v                  v
        Ableton            TouchDesigner
            |                  |
       synth / fx          3D / feedback
            |                  |
            +--------+---------+
                     |
                     v
              shared parameters
                     |
                     v
                  AI texture
----

Strudel은 시간 구조와 패턴을 작곡하고, Ableton은 실제 음색을 담당하며, TD는 그 결과를 시각 공간으로 번역한다.

== 12. Performance Philosophy

최종 공연 화면에서는 TouchDesigner UI를 직접 조작하지 않는 것을 목표로 한다.

[source,text]
----
                 STRUDEL REPL
                      |
                live coding
                      |
        +-------------+-------------+
        |             |             |
      music         motion        material
        |             |             |
        +-------------+-------------+
                      |
                     OSC
                      |
                      v
                TOUCHDESIGNER
                      |
                realtime render
                      |
                      v
                  PROJECTOR
----

즉 공연자는 Strudel만 보면서 다음을 동시에 제어한다.

* 음악 패턴
* 악기별 amplitude
* 3D motion
* camera / scale / rotation
* layer alpha
* feedback amount
* scene selection
* material / texture / style
* AI texture generation timing

== 13. AI Prompt System

긴 자연어 prompt 하나를 직접 라이브 코딩하기보다 semantic vocabulary를 사용하는 것이 목표다.

=== 13.1 Prompt Components

[source,text]

material

style
lighting

----

=== 13.2 Example

[source,javascript]
----
.scene("organic-sphere")
.material("wet-fungal")
.surface("translucent-fibrous")
.style("dark-biological")
.lighting("soft-side")
.palette("black-amber")
.detail("micro-texture")

예:

[source,text]

----

== 14. Example Performance Flow

[source,text]
----
INTRO
  sphere only
  low alpha
  sparse particles

BUILD
  bass deformation increases
  pad membrane slowly appears
  AI generates translucent-fabric variation

DROP
  kick controls sphere pulse
  bass controls mass/deformation
  pad membrane expands
  snare injects feedback
  hi-hat increases particle jitter

BREAK
  geometry nearly stops
  feedback persists
  AI texture slowly evolves

DROP 2
  new material prompt
  new texture generated
  existing geometry remains
  new AI appearance enters through crossfade
----

== 16. Core Principle

[quote]
같은 음악 파라미터가 소리와 물질을 동시에 연주한다.

음악은 단순한 비주얼 트리거가 아니라, 3D 공간의 움직임과 AI가 생성하는 물질의 상태를 함께 작곡한다.

TouchDesigner는 그 상태를 실시간으로 물질화하고, AI는 새로운 질감을 공급하며, feedback은 그 질감을 시간 속에서 계속 변형한다.
